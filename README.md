## 📖 About This Book

Welcome to the companion repository for **"Hands-on Deep Learning based Image Processing using Google Colab"** by **Yasser Baleghi**.

This book bridges the gap between **classical digital image processing**  and **modern deep learning approaches**, all within the accessible, free, and collaborative environment of **Google Colab**.

Whether you are:
- A student learning image processing for the first time
- A professional transitioning from MATLAB to Python
- An instructor seeking a modern, code-first textbook
- A researcher wanting to apply deep learning to image processing tasks

...this book is designed for you.

## 🚀 Quick Start

### The Easiest Way: Open in Colab

1. Click the **"Open In Colab"** badge at the top of this README or on any notebook.
2. The notebook will open in Google Colab with all code ready to run.
3. Start coding immediately – no installation required!

👉 **[Click here to open the master index in Colab](https://colab.research.google.com/github/Yasser-Baleghi/hands-on-dl-image-processing/blob/main/index.ipynb)**

## 🔧 System Requirements

### For Google Colab (Recommended)
- A Google account (free)
- Internet connection
- No local installation required!

### For Local Execution (Optional)
- Python 3.8 or higher
- Jupyter Notebook or Jupyter Lab
- Required packages (see `requirements.txt`)

To install dependencies locally:

```bash
pip install -r requirements.txt
```
